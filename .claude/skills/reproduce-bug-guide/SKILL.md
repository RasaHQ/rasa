# Reproduce Bug Guide

## When to use
Use when a product bug is suspected and reproduction steps are needed.

## Instructions
1. Prefer the smallest test or CLI command that reproduces the failure.
2. Include environment or config prerequisites if required.
3. Avoid vague steps; be explicit about inputs and commands.

## Output format
- Preconditions
- Steps
- Expected vs actual
