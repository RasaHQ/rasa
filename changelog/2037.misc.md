Log error and raise an exception if DynamoDB table is not found when Rasa is run with multiple sanic workers.
Having multiple Sanic workers in Rasa would lead to a race condition in initialising DynamoDB table, resulting in 
failure to start many of the workers. To remedy this race condition we instruct the customer to either use a single
worker or to pre-create the DynamoDB table before starting Rasa with multiple workers or to create the table in the
DynamoDB manually.
