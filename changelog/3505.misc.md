Added response classification evaluator for Copilot predictions.

The evaluator computes precision, recall, and F1-score metrics for special tokens:
`[ERROR_FALLBACK]`, `[ROLEPLAY_REQUEST_DETECTED]`, `[OUT_OF_SCOPE_REQUEST_DETECTED]`,
and `[NO_KNOWLEDGE_BASE_ACCESS]`.

Metrics (precision, recall, f1) are calculated both per-class and overall using micro,
macro, and weighted averaging methods.

**Key components:**
- `ResponseClassificationEvaluator` for calculating per-class and overall metrics
- `ResponseClassificationLangfuseRunner` for running experiments and exporting results
- CLI interface with environment validation for running experiments
- Thread-safe experiment execution with parallel processing support
