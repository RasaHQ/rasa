Add support for [`pypred`](https://github.com/armon/pypred) predicates in conditional response variations, similar to
the usage of predicates in flows. The `condition` key in a response variation can now also be a string predicate 
that supports only the `slots` namespace. One of many logical operators supported is `not`.

Deprecate the former list of dictionaries format for the `condition` key in a response variation.
