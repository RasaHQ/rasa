Converted MCP project context from resources to tools. The Rasa Copilot MCP server now
exposes project context as callable tools with structured Pydantic responses instead of
read-only resources.

Removed resources `project://flows`, `project://domain`, and `project://actions`.

Added tools `list_project_flow_definitions`, `list_project_slot_fadefinitions`, 
`list_project_response_definitions`, `list_project_custom_actions_in_domain`, and 
`list_default_action_names`, which return structured metadata (e.g. flow id/name/path,
slot name/type/path) and support optional `data_folder` and `domain_folder` parameters.

The documentation search tool was renamed from `search_docs` to `search_rasa_documentation`, and tool descriptions were updated for clarity and consistency.
