Migrate from the deprecated `langchain_community.vectorstores.qdrant.Qdrant` to the maintained `langchain_qdrant.QdrantVectorStore`,
which uses the new `query_points` API under the hood and is compatible with qdrant-client `1.10+`.

Pin langchain-qdrant = "~0.2.1" because it's the last release that still supports our current langchain-core ~= 0.3.81
(1.0+ requires langchain-core ≥ 1.0) and it allows qdrant-client >= 1.10.1, < 2.0.0, which encompasses 1.17.1 upgrade of `qdrant-client` in this PR.
