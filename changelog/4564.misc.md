Exposed Rasa's official schemas (flow, domain, and E2E test) as MCP tools to enable
validation and generation of YAML files' syntax in the Rasa Assistant project.
Added three new MCP schema tools: `get_flow_schema()` (returns JSON Schema for flow
validation), `get_domain_schema()` (returns YAML schema for domain validation including
slots, actions, and responses), and `get_e2e_schema()` (returns YAML schema for E2E test
validation). All tools support a `calm_only` parameter (default: true) to filter out
NLU-related properties.
