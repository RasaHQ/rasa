
- Decoupled Guardrails from Lakera AI by refactoring the architecture.
- Renamed `lakera.py` to `clients.py` and introduced a new `GuardrailsClient` ABC for future implementations.
- Added a `GuardrailsPolicyChecker` class to centralize policy violation logic that was previously scattered in `guardrails/utils.py`.
- Introduced an `ENABLE_GUARDRAILS` environment variable (defaults to false) to provide control over guardrail calls.
- Renamed configuration variables to be more explicit: `LAKERA_ASSISTANT_HISTORY_GUARDRAIL_PROJECT_ID` and `LAKERA_COPILOT_HISTORY_GUARDRAIL_PROJECT_ID`.
- Updated service integration to use the new `GuardrailsPolicyChecker` instead of direct utility functions, improving code organization and maintainability.
