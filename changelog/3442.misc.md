Added tracing integration with Langfuse for `Copilot` and `InkeepDocumentRetrieval` features.

**What gets tracked:**
- Assistant context and current files being worked on
- All LLM interactions including input messages, generated responses, and token usage costs. Added new environment variables for configuring the Copilot's token pricing per 1K: `COPILOT_INPUT_TOKEN_PRICE`, `COPILOT_OUTPUT_TOKEN_PRICE`, and `COPILOT_CACHED_TOKEN_PRICE`.
- Document retrieval operations with usage statistics
- Complete user requests and final responses from the `/copilot` endpoint

**Trace metadata includes:**
- User ID, project ID, and chat history ID for better debugging and analytics

**Cost statistics improvements:**
- Updated `UsageStatistics` to calculate accurate costs including cached tokens.
