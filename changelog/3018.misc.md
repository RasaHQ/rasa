Enhanced copilot functionality with improved error handling and templated responses.
Added new role `ROLE_COPILOT_INTERNAL` for Rasa system requests, new response categories
for error analysis (`ERROR_FALLBACK`, `TRAINING_ERROR_LOG_ANALYSIS`,
`E2E_TESTING_ERROR_LOG_ANALYSIS`).
Added new `LogContent` type for structured log handling. Introduced templated utterances
for internal messages and moved copilot responses to dedicated YAML files.
Exposed `/copilot/internal_message_templates/<template_name>` endpoint for frontend
access to templated utterances.
